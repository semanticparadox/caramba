Coinbase Commerce — крипта для мирового рынка

Платёжная платформа от Coinbase для приёма криптовалют от пользователей по всему миру. Требует Coinbase-аккаунт. 1% комиссии, широкая поддержка монет, простая интеграция.

Мировой рынок Крипта KYC: лёгкий (Coinbase account) Комиссия: 1% BTC · ETH · USDC · LTC · BCH · DAI

Когда подойдёт

  • Ваша аудитория — международная; нужен надёжный крипто-процессор с хорошей репутацией.
  • Пользователи уже используют Coinbase и хотят платить напрямую с него.
  • Нужна поддержка USDC (стейблкоин Coinbase) для исключения волатильности.
  • Важна простота: минимум настроек, один API-ключ, понятная документация.

Регистрация

  1. Если у вас ещё нет аккаунта Coinbase — зарегистрируйтесь на coinbase.com (требует email и верификацию личности через Coinbase).
  2. Откройте commerce.coinbase.com и войдите через ваш Coinbase-аккаунт.
  3. Создайте Commerce-аккаунт: укажите название бизнеса и сайт.
  4. После входа в Commerce Dashboard перейдите в Settings → API Keys.

Где взять ключи

  1. В кабинете Coinbase Commerce перейдите: Settings → API Keys.
  2. Нажмите Create API Key — скопируйте сгенерированный ключ.
  3. Для Webhook Secret: перейдите в Settings → Webhook subscriptions → Add an endpoint → введите URL webhook (см. ниже) → после сохранения скопируйте Signing Secret.
  4. Вставьте:
    • API Key → «Coinbase Commerce API Key» (coinbase_api_key)
    • Webhook Signing Secret → «Coinbase Webhook Secret» (coinbase_webhook_secret)
  5. Переключатель coinbase_enabled включите в настройках панели после сохранения ключей.

Webhook URL

Добавьте в кабинет Coinbase Commerce следующий URL для уведомлений:

{{ panel_url }}/api/webhooks/payment/coinbase_commerce

Где настроить: Settings → Webhook subscriptions → Add an endpoint. Вставьте URL выше. Выберите события: charge:confirmed, charge:failed, charge:pending. После сохранения скопируйте Signing Secret.

Особенности

  • Проверка подписи: заголовок X-CC-Webhook-Signature. Значение — HMAC-SHA256 hex от тела запроса, ключ — ваш Webhook Signing Secret. Панель проверяет автоматически.
  • Coinbase Commerce работает с Managed Wallets — средства поступают напрямую на ваш Coinbase-кошелёк или внутренний кошелёк Commerce. Вывод — через интерфейс Coinbase.
  • Из России доступ к сайту Coinbase может быть ограничен. Пользователям из РФ нужен VPN для покупки крипты на Coinbase, но платёж через Commerce работает без ограничений по IP.
  • Coinbase Commerce НЕ поддерживает Lightning Network — только on-chain Bitcoin.
  • Charge истекает через 1 час после создания, если оплата не поступила.

Тестирование

  1. Coinbase Commerce не предоставляет официальный sandbox. Для тестирования используйте реальные транзакции на малые суммы.
  2. Создайте инвойс на минимальную сумму (например, $0.50 в USDC) через панель и оплатите его с тестового кошелька.
  3. Проверьте получение webhook в Settings → Webhook subscriptions → ваш endpoint → Delivery Attempts.

Возможные проблемы

  • Webhook не приходит → убедитесь, что endpoint добавлен и URL панели доступен по HTTPS. Посмотрите Delivery Attempts в кабинете Commerce.
  • Подпись не совпадает → убедитесь, что используется именно Signing Secret из раздела Webhooks, а не API Key. Это разные значения.
  • Charge в статусе «unresolved» → пользователь отправил неверную сумму или в несколько транзакций. Вручную проверьте в кабинете Commerce и при необходимости запросите доплату или верните средства.
  • Аккаунт Commerce заморожен → Coinbase может заморозить Commerce при подозрительной активности. Свяжитесь с поддержкой Coinbase, предоставив информацию о вашем бизнесе.
