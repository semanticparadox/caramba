NOWPayments — 200+ криптовалют, минимальный KYC

Глобальный крипто-процессинг с поддержкой более 200 монет. Не требует юридического лица; KYC появляется только при значительных объёмах. Комиссия от 0.5%.

Крипта KYC: минимальный (при больших объёмах) Комиссия: 0.5% 200+ валют

Когда подойдёт

  • Нужна максимальная поддержка криптовалют — NOWPayments принимает более 200 монет.
  • Вы хотите работать без регистрации ИП и с минимальными требованиями к документам.
  • Ваша аудитория — международная; NOWPayments работает глобально, включая пользователей из РФ.
  • Нужен автоматический конвертер: NOWPayments позволяет мгновенно конвертировать полученную крипту в стейблкоины.

Регистрация

  1. Откройте nowpayments.io и нажмите Sign Up.
  2. Укажите email и пароль. Подтвердите email — письмо приходит в течение 1–2 минут.
  3. Войдите в кабинет. Для небольших объёмов KYC не требуется сразу — можно начать принимать платежи сразу после регистрации.
  4. Перейдите в Store Settings — задайте название магазина и основную валюту для расчётов.

Где взять ключи

  1. В кабинете перейдите: Store Settings → API Keys.
  2. Нажмите Generate API Key — скопируйте полученный ключ (поле API Key).
  3. Там же нажмите Generate IPN Secret Key — скопируйте значение (поле IPN Secret).
  4. Вставьте API Key в поле «NOWPayments API Key», а IPN Secret — в поле «NOWPayments IPN Secret» в настройках панели.

Webhook URL

Добавьте в кабинет NOWPayments следующий URL для IPN-уведомлений:

{{ panel_url }}/api/webhooks/payment/nowpayments

Где настроить: Store Settings → IPN URL. Вставьте URL выше и сохраните. Убедитесь, что поле IPN Enabled включено.

Особенности

  • Проверка подписи: заголовок x-nowpayments-sig. Значение — HMAC-SHA512 от тела JSON-запроса, ключ — ваш IPN Secret. Панель проверяет автоматически.
  • NOWPayments не является банком; вывод — на крипто-кошелёк по запросу из кабинета.
  • Из-за курсовых колебаний итоговая сумма в крипте может незначительно отличаться от выставленной — это нормально.
  • В РФ NOWPayments доступен без VPN; если возникают блокировки, используйте API напрямую (панель общается по API, а не через сайт).

Тестирование

  1. NOWPayments предоставляет sandbox: перейдите в sandbox.nowpayments.io и создайте отдельный аккаунт.
  2. Получите sandbox API Key в том же разделе Store Settings → API Keys.
  3. Временно замените API Key в настройках панели на sandbox-ключ, создайте тестовый инвойс и симулируйте оплату через sandbox-интерфейс.
  4. После тестирования верните продакшн-ключ.

Возможные проблемы

  • Webhook не приходит → убедитесь, что IPN URL сохранён и IPN Enabled включён. Посмотрите лог в Store Settings → IPN Logs.
  • Подпись не совпадает → убедитесь, что вы используете IPN Secret, а не API Key. Это разные поля.
  • Платёж «partially paid» → пользователь отправил меньше нужной суммы. Панель обрабатывает такой статус как незавершённый; пользователь должен доплатить на тот же адрес.
  • Валюта недоступна → не все 200+ монет активны по умолчанию. Активируйте нужные в Store Settings → Currencies.
