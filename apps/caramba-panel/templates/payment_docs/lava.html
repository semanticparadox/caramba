Lava.ru — карты и СБП для физлиц в России

Российский платёжный агрегатор, работающий с физлицами без ИП. Принимает оплату банковскими картами РФ и по СБП. Лимит оборота до 600 000 ₽/месяц без регистрации ИП.

Для РФ без ИП KYC: лёгкий (паспорт) Комиссия: уточняйте в кабинете Лимит: до 600 000 ₽/мес Карты РФ · СБП

Когда подойдёт

  • Ваша аудитория — пользователи в России, которые хотят платить рублями картой или через СБП.
  • Вы физлицо без ИП и ваш оборот не превышает 600 000 ₽ в месяц.
  • Нужна интеграция с российскими банками без открытия расчётного счёта.
  • Требуется простая и быстрая настройка с минимальным пакетом документов.

Регистрация

  1. Откройте lava.ru и нажмите Регистрация.
  2. Укажите email, придумайте пароль, подтвердите адрес электронной почты.
  3. Перейдите в раздел Профиль → Верификация: загрузите скан паспорта (разворот с фото). Верификация занимает 1–3 рабочих дня.
  4. После подтверждения перейдите в Мерчант → Создать проект и настройте ваш магазин.

Где взять ключи

  1. В кабинете перейдите: Мерчант → ваш проект → Настройки → API.
  2. Скопируйте Ключ магазина (Shop ID) и Секретный ключ.
  3. Вставьте Shop ID в поле «Lava Shop ID», а Секретный ключ — в поле «Lava Secret Key» в настройках панели.

Webhook URL

Добавьте в кабинет Lava следующий URL для уведомлений об оплате:

{{ panel_url }}/api/webhooks/payment/lava

Где настроить: Мерчант → ваш проект → Настройки → Webhook URL. Вставьте URL выше в соответствующее поле и сохраните изменения.

Особенности

  • Проверка подписи: заголовок Signature. Значение — HMAC-SHA256 от тела запроса, ключ — ваш Секретный ключ. Панель проверяет автоматически.
  • API для создания инвойса: POST api.lava.ru/business/invoice/create.
  • Лимит 600 000 ₽/месяц — при превышении Lava может запросить дополнительные документы или потребовать регистрацию ИП.
  • Средства хранятся на балансе в кабинете; вывод — на карту или расчётный счёт.
  • Работает только с картами российских банков и через СБП. Зарубежные карты не поддерживаются.

Тестирование

  1. Lava предоставляет тестовый магазин: при регистрации вы получаете тестовый проект с префиксом «Test». Переключитесь на него в кабинете.
  2. Создайте тестовый инвойс на 1 ₽ через панель. Lava автоматически проведёт тестовую оплату без списания средств.
  3. Для продакшна переключитесь на реальный проект и замените ключи в настройках панели.

Возможные проблемы

  • Webhook не приходит → проверьте, что URL панели доступен снаружи (не localhost/VPN). В кабинете Lava посмотрите лог попыток в разделе Webhook Logs.
  • Подпись не совпадает → убедитесь, что скопирован именно Секретный ключ, а не Shop ID. Они имеют разный формат.
  • Верификация отклонена → перезагрузите скан паспорта в хорошем качестве (не менее 300 DPI), без засветов и отрезанных краёв.
  • Инвойс не создаётся → проверьте, что проект активирован и не находится в режиме «Заблокирован».
