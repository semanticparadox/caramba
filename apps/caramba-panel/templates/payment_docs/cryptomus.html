Cryptomus — мультикрипто-агрегатор с низкой комиссией

Мерчант-платформа для приёма более 100 криптовалют. Подходит физлицам без ИП, требует email и 2FA. В периоды блокировок в РФ используйте как резервный провайдер.

Крипта KYC: лёгкий (email + 2FA) Комиссия: 0.4–1% 100+ криптовалют

Когда подойдёт

  • Нужна широкая поддержка криптовалют при минимальной комиссии (от 0.4%).
  • Вы физлицо без ИП — Cryptomus не требует юридического лица для merchant-аккаунта.
  • Используйте как резервный канал при недоступности основного провайдера.
  • Ваши пользователи за рубежом — Cryptomus доступен глобально.

Регистрация

  1. Откройте cryptomus.com и нажмите Sign Up.
  2. Укажите email и пароль. Подтвердите email — письмо придёт в течение 1–2 минут.
  3. После входа обязательно включите 2FA (раздел Security) — без него API-ключи недоступны.
  4. Перейдите в Merchant → Overview — это ваш рабочий кабинет.

Где взять ключи

  1. В кабинете перейдите: Merchant → Settings → API Keys.
  2. Нажмите Generate Payment Key — скопируйте значение поля Payment API Key.
  3. Нажмите Generate Merchant ID (или найдите его в том же разделе) — скопируйте Merchant UUID.
  4. Вставьте Payment API Key в поле «Cryptomus Payment API Key», а Merchant UUID — в поле «Cryptomus Merchant ID» в настройках панели.

Webhook URL

Добавьте в кабинет Cryptomus следующий URL для уведомлений об оплате:

{{ panel_url }}/api/webhooks/payment/cryptomus

Где настроить: Merchant → Settings → Webhooks → поле URL. Активируйте события payment.completed и payment.failed.

Особенности

  • Проверка подписи: заголовок sign. Значение — MD5 от конкатенации base64(тело запроса) + api_key. Панель проверяет автоматически.
  • В РФ Cryptomus периодически попадает под блокировки провайдеров: настройте его как резервный канал после основного провайдера (например, CryptoBot или OxaPay).
  • Вывод средств — на крипто-кошелёк без банковских ограничений.
  • Минимальная сумма выплаты зависит от монеты (уточните в Merchant → Payouts).

Тестирование

  1. Cryptomus предоставляет тестовый режим: перейдите в Merchant → Settings → Test Mode и включите переключатель.
  2. В тестовом режиме создайте инвойс через панель — оплата симулируется автоматически без реальных средств.
  3. Для возврата в рабочий режим отключите Test Mode в тех же настройках.

Возможные проблемы

  • Webhook не приходит → проверьте, что URL панели доступен снаружи. В разделе Merchant → Settings → Webhooks → Logs посмотрите историю попыток отправки.
  • Подпись не совпадает → убедитесь, что вы используете именно Payment API Key, а не Payout API Key — это разные ключи.
  • Сайт недоступен из РФ → используйте VPN для входа в кабинет или зайдите через Tor. Сами платежи от пользователей при этом работают через API и не зависят от доступности сайта.
  • Merchant не активирован → перейдите в Merchant → Overview и убедитесь, что статус «Active», а не «Pending».
