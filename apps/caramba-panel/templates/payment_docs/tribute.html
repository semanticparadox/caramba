Tribute — монетизация в Telegram для авторов и создателей

Telegram-нативная платформа для creator economy. Не требует ИП, бизнес-аккаунта или верификации. Идеально для Mini App — пользователь платит прямо в Telegram без выхода в браузер.

Telegram-native KYC: нет Комиссия: 5% Оплата: через Telegram

Когда подойдёт

  • Вы хотите монетизировать контент или услуги прямо внутри Telegram без юридического лица.
  • Ваша аудитория — Telegram-пользователи; оплата происходит нативно, без перехода на внешние сайты.
  • Нужен самый простой старт: Tribute активируется за несколько минут через Telegram-бота.
  • Комиссия 5% — приемлемый уровень для Telegram-нативного решения без KYC.

Регистрация

  1. Откройте бота tribute.tg или найдите @tributeapp в Telegram.
  2. Нажмите Start и следуйте инструкциям: подключите ваш Telegram-аккаунт или бота.
  3. Создайте продукт или подписку — Tribute позволяет задать разные тарифы и описания.
  4. Никаких документов не требуется — только Telegram-аккаунт.

Где взять ключи

  1. В личном кабинете Tribute (через Telegram-бота или веб-интерфейс) перейдите в Settings → API / Integrations.
  2. Скопируйте API Key — это ваш ключ для создания ссылок на оплату через API.
  3. Скопируйте Webhook Secret — он используется для верификации входящих уведомлений от Tribute.
  4. Вставьте:
    • API Key → поле «Tribute API Key» (tribute_api_key)
    • Webhook Secret → поле «Tribute Webhook Secret» (tribute_webhook_secret)

Webhook URL

Добавьте в кабинет Tribute следующий URL для уведомлений об оплате:

{{ panel_url }}/api/webhooks/payment/tribute

Где настроить: Settings → Webhooks → Add Webhook URL. Вставьте URL выше. Убедитесь, что события оплаты (payment.completed) включены.

Особенности

  • Проверка подписи: заголовок X-Tribute-Signature. Значение — HMAC-SHA256 от тела запроса, ключ — ваш Webhook Secret. Панель проверяет автоматически.
  • Tribute — это creator-платформа; некоторые функции (например, рекуррентные подписки) могут быть реализованы иначе, чем в классических процессорах.
  • Вывод средств — через механизм Tribute (уточните способы в кабинете). Налоговая ответственность — на вас как на физлице.
  • Если вы используете Tribute вместе с ботом: убедитесь, что ваш бот подключён к Tribute в настройках интеграции.

Тестирование

  1. Уточните наличие тестового режима в документации Tribute (tribute.tg).
  2. Если sandbox недоступен: сделайте тестовую оплату минимальной суммы через Mini App, используя свой аккаунт.
  3. Проверьте получение webhook в разделе Logs панели.

Возможные проблемы

  • Webhook не приходит → убедитесь, что URL панели доступен по HTTPS. Tribute требует валидный TLS-сертификат.
  • Подпись не совпадает → убедитесь, что Webhook Secret скопирован полностью без лишних пробелов или символов переноса строки.
  • API Key не работает → проверьте, что вы используете ключ из раздела API / Integrations, а не токен бота или другой идентификатор.
  • Оплата не отображается в панели → проверьте логи (Logs → фильтр tribute). Убедитесь, что переключатель tribute_enabled включён в настройках.
