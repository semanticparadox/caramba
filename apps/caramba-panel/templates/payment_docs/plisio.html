Plisio

Криптоплатёжный шлюз с поддержкой BTC, ETH, LTC, XMR и других валют. Регистрация без KYC, комиссия 0.5%.

Регистрация

  1. Создайте аккаунт на plisio.net.
  2. В личном кабинете создайте новый магазин (Stores → Add new store).
  3. Скопируйте Secret key из настроек магазина.

Webhook

  1. Перейдите в Stores → ваш магазин → Settings.
  2. Вставьте Webhook URL из карточки выше в поле Callback URL.
  3. Сохраните настройки.

Заполните поля

  • API Key — Secret key из настроек магазина Plisio.
