Stripe — международные карты, не для РФ-аудитории

Ведущий мировой платёжный процессор. Требует верифицированного бизнеса за пределами РФ. Используйте для пользователей из Европы, США и других стран — но не для российской аудитории.

Мировой рынок KYC: полный (верификация бизнеса) Комиссия: 1.4–2.9% + фиксированная Карты: Visa · Mastercard · AMEX · и др.

Когда подойдёт

  • Ваши пользователи — за пределами России и хотят платить международными картами.
  • У вас есть юридическое лицо или ИП за рубежом (Казахстан, Армения, Грузия, ОАЭ и т.д.).
  • Нужна самая широкая поддержка карточных систем и встроенная антифрод-проверка.
  • Планируется подписочная модель с автосписанием — Stripe отлично подходит для recurring billing.

Регистрация

  1. Откройте stripe.com и нажмите Start now.
  2. Укажите email, страну регистрации бизнеса (выбирайте страну, где у вас есть юрлицо или счёт), пароль.
  3. Пройдите верификацию: укажите данные бизнеса, ИНН, адрес, тип деятельности. Загрузите документы, подтверждающие личность директора/учредителя.
  4. После верификации перейдите в Dashboard → Developers → API Keys.

Где взять ключи

  1. В кабинете перейдите: Developers → API Keys.
  2. Скопируйте Secret key (начинается с sk_live_...). Внимание: не путайте с Publishable key — для сервера нужен именно Secret key.
  3. Вставьте Secret key в поле «Stripe Secret Key» в настройках панели.
  4. Для webhook signature: создайте endpoint (см. ниже) — Stripe покажет Webhook Signing Secret (whsec_...). Вставьте его в поле «Stripe Webhook Secret».

Webhook URL

Добавьте в кабинет Stripe следующий URL для уведомлений:

{{ panel_url }}/api/webhooks/payment/stripe

Где настроить: Developers → Webhooks → Add endpoint. Вставьте URL выше. В разделе Events to send выберите: checkout.session.completed, invoice.paid, invoice.payment_failed, customer.subscription.deleted. После сохранения скопируйте Signing secret.

Особенности

  • Проверка подписи: заголовок Stripe-Signature. Stripe использует HMAC-SHA256 с таймстампом против replay-атак. Панель проверяет автоматически через официальную Stripe SDK-логику.
  • Stripe не работает напрямую с российскими картами и счётами. Для приёма платежей от РФ-пользователей используйте Lava, AAIO или WATA.
  • Stripe доступен в 46+ странах — уточните, поддерживается ли страна вашего юрлица на stripe.com/global.
  • Рекуррентные подписки (Stripe Subscriptions) требуют отдельной настройки продукта и цены в Product Catalog. Панель поддерживает одноразовые платежи через Checkout Session.

Тестирование

  1. Stripe предоставляет тестовый режим: в кабинете переключите тоггл Test mode (правый верхний угол).
  2. В тестовом режиме используйте тестовые ключи (sk_test_...) и тестовые карты. Карта для успешного платежа: 4242 4242 4242 4242, любая дата и CVV.
  3. Создайте отдельный webhook endpoint для тест-режима с тем же URL — Stripe разделяет live и test webhooks.

Возможные проблемы

  • Webhook не приходит → убедитесь, что endpoint создан в нужном режиме (live/test). В кабинете Developers → Webhooks → ваш endpoint → Logs видна история доставки.
  • Подпись не совпадает → чаще всего причина в том, что тело запроса читается как строка, а не как raw bytes. Панель использует корректный способ чтения.
  • Аккаунт заблокирован → Stripe строго проверяет деятельность. Убедитесь, что ваш сайт содержит чёткое описание услуги, условия использования и политику возвратов.
  • Платёж отклонён с кодом card_declined → в тестовом режиме используйте именно тестовые карты. В продакшне это означает отказ банка — пользователь должен связаться со своим банком.
