CryptoBot — нативная крипто-оплата через Telegram

Бот от команды Telegram для приёма USDT, TON, BTC и других монет прямо внутри мессенджера. Идеально для аудитории, которая уже пользуется Telegram-кошельком.

Telegram-native KYC: нет Комиссия: 3% Лимит: до ~$1 000 за сделку без KYC Валюты: USDT · TON · BTC · ETH · BNB · TRX

Когда подойдёт

  • Ваша аудитория — Telegram-пользователи, у которых уже есть @wallet или другой крипто-кошелёк.
  • Вы хотите принимать крипту без регистрации юридического лица и без KYC.
  • Средний чек подписки не превышает ~$1 000 в одной транзакции.
  • Нужна простая интеграция: CryptoBot работает через единый API без сложной инфраструктуры.

Регистрация

  1. Откройте бота t.me/CryptoBot в Telegram и нажмите Start.
  2. Перейдите в раздел Pay (кнопка в меню) → My Apps → Create App.
  3. Придумайте название приложения (например, «Caramba VPN»), нажмите Save.
  4. Готово — никаких документов не требуется, только аккаунт в Telegram.

Где взять ключи

  1. В боте @CryptoBot перейдите Pay → My Apps и выберите ваше приложение.
  2. Нажмите API Token — скопируйте строку вида 12345:AABBccDDeeFF....
  3. Вставьте этот токен в поле «CryptoBot API Token» в настройках панели (вкладка Payments).

Webhook URL

Добавьте в кабинет CryptoBot следующий URL для получения уведомлений об оплате:

{{ panel_url }}/api/webhooks/payment/cryptobot

Где настроить: @CryptoBot → Pay → My Apps → ваше приложение → Webhooks → Add Webhook. Вставьте URL выше и выберите событие invoice_paid.

Особенности

  • Проверка подписи: заголовок запроса — crypto-pay-api-signature. Значение — HMAC-SHA256 от тела запроса, ключ — SHA256-хэш вашего API-токена. Панель проверяет это автоматически.
  • Выводить средства можно прямо на любой крипто-кошелёк без ограничений — CryptoBot не является банком.
  • Лимит $1 000 за транзакцию без верификации; при необходимости Telegram предложит пройти дополнительную проверку.
  • В России CryptoBot работает стабильно, так как работает через инфраструктуру Telegram.

Тестирование

  1. CryptoBot не имеет официального sandbox. Для теста создайте инвойс на минимальную сумму (например, 0.01 USDT) через панель и оплатите его вручную со своего кошелька.
  2. Проверьте, что панель получила webhook: раздел Logs → фильтр по cryptobot.

Возможные проблемы

  • Webhook не приходит → убедитесь, что URL панели доступен снаружи (не localhost). Проверьте раздел Webhooks в @CryptoBot — должен быть статус «Active».
  • Подпись не совпадает → убедитесь, что в поле токена сохранён именно токен приложения из раздела Pay, а не Bot Token из @BotFather.
  • Invoice в статусе «expired» → по умолчанию инвойс живёт 1 час. Убедитесь, что пользователь не затягивает оплату. Срок задаётся параметром expires_in при создании инвойса (панель использует 3600 секунд).
