CrystalPay — СБП и крипта в одном агрегаторе

Российский агрегатор, объединяющий оплату через СБП, карты и криптовалюты. Работает с физлицами. Подходит, если нужен один провайдер для всех типов оплаты.

Для РФ без ИП Крипта KYC: лёгкий Комиссия: 4–7% СБП · Карты РФ · Крипта

Когда подойдёт

  • Нужен единый провайдер для рублёвых платежей (СБП, карты) и крипты одновременно.
  • Вы физлицо без ИП — CrystalPay работает с физлицами.
  • Ваша аудитория смешанная: часть платит рублями, часть — криптой.
  • Комиссия 4–7% приемлема в обмен на охват всех популярных методов оплаты.

Регистрация

  1. Откройте crystalpay.io и нажмите Регистрация.
  2. Укажите логин (латиница), email и пароль. Подтвердите email.
  3. В личном кабинете создайте кассу: Кассы → Создать кассу. Укажите название вашего магазина.
  4. Пройдите минимальную верификацию (email подтверждение + номер телефона).

Где взять ключи

  1. В кабинете перейдите: Кассы → ваша касса → Настройки → API.
  2. Скопируйте Логин кассы (он совпадает с вашим логином регистрации или логином кассы).
  3. Скопируйте Секретный ключ (Secret).
  4. Скопируйте Salt — дополнительный параметр для формирования подписи webhook.
  5. Вставьте:
    • Логин → поле «CrystalPay Login» (crystalpay_login)
    • Секретный ключ → поле «CrystalPay Secret» (crystalpay_secret)
    • Salt → поле «CrystalPay Salt» (crystalpay_salt)

Webhook URL

Добавьте в кабинет CrystalPay следующий URL для уведомлений:

{{ panel_url }}/api/webhooks/payment/crystalpay

Где настроить: Кассы → ваша касса → Настройки → Callback URL. Вставьте URL выше и сохраните.

Особенности

  • Проверка подписи: заголовок X-Crystalpay-Signature. Значение — HMAC-SHA1 от строки id:type:hash с использованием Salt в качестве ключа. Панель проверяет автоматически.
  • CrystalPay поддерживает как фиатные методы (СБП, карты), так и криптовалюты (BTC, ETH, USDT и др.) — в одном API.
  • Выплаты происходят на внутренний баланс кассы; вывод — через интерфейс кабинета.
  • Комиссия зависит от метода оплаты: СБП — ниже, крипта — может быть выше. Уточняйте тарифы в кабинете.

Тестирование

  1. CrystalPay предоставляет тестовую кассу — при регистрации создаётся тестовая среда. Уточните её наличие в документации на сайте или через поддержку.
  2. Если тестового режима нет: создайте инвойс на 1 ₽ через панель и оплатите вручную через СБП.
  3. Проверьте получение webhook в разделе Logs панели.

Возможные проблемы

  • Webhook не приходит → убедитесь, что Callback URL сохранён и URL панели доступен снаружи по HTTPS.
  • Подпись не совпадает → убедитесь, что все три параметра (Login, Secret, Salt) заполнены правильно. SHA1 чувствителен к лишним пробелам.
  • Неверный логин → используйте именно логин кассы (отображается в настройках кассы), а не email регистрации.
  • Метод оплаты недоступен → в кабинете проверьте, какие методы активированы для вашей кассы (Настройки → Методы оплаты).
