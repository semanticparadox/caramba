Telegram Stars — встроенная валюта Telegram

Нативная валюта Telegram для монетизации внутри Mini App и ботов. Не требует KYC и юридического лица. Настраивается через @BotFather — панель только показывает или скрывает эту опцию у пользователей.

Telegram-native KYC: нет Комиссия: берёт Telegram (~30%) Курс: ~$0.013 за 1 Star

Когда подойдёт

  • Ваши пользователи — активные пользователи Telegram Premium, у которых уже есть Stars на балансе.
  • Хотите предложить оплату без привязки банковской карты — Stars покупают через Telegram в один клик.
  • Нет возможности подключить карточный процессинг, но нужен хоть какой-то способ оплаты.
  • Небольшие суммы подписки — Stars оптимальны для платежей до ~$5–10 в месяц.

Регистрация

  1. Telegram Stars не требует отдельной регистрации. Нужен только бот, созданный через @BotFather.
  2. Убедитесь, что ваш Bot Token уже заполнен в настройках панели (вкладка General → Bot Token).
  3. В @BotFather выполните команду /mybots → выберите вашего бота → Bot Settings → Configure Stars → следуйте инструкциям для активации приёма Stars.

Настройка в панели

  1. На вкладке Payments найдите переключатель «Telegram Stars».
  2. Включите переключатель (telegram_stars_enabled) — после этого опция Stars появится в Mini App у пользователей при выборе способа оплаты.
  3. Курс (Stars за месяц подписки) рассчитывается автоматически из цены плана в USD и текущего курса Telegram (~$0.013/Star). Telegram устанавливает курс сам — в панели ручная установка не нужна.

Webhook URL

Для Telegram Stars webhook настраивается автоматически через Bot API — отдельный URL вводить не нужно. Панель получает уведомления через механизм SuccessfulPayment update от Telegram Bot API.

Убедитесь, что webhook вашего бота указывает на:

{{ panel_url }}/api/webhooks/telegram

Это уже настроено, если панель работает в штатном режиме (бот активен).

Особенности

  • Telegram берёт ~30% комиссии с покупок Stars через App Store/Google Play. При прямой покупке через Telegram Web комиссия ниже.
  • Возврат Stars пользователю возможен через Bot API (refundStarPayment). Панель поддерживает возвраты из раздела Transactions.
  • Stars нельзя вывести напрямую в фиатные деньги самостоятельно — Telegram планирует программу монетизации для разработчиков. Уточняйте актуальные условия в документации Telegram.
  • PreCheckoutQuery — это временный запрос перед оплатой. На него обязательно нужно ответить в течение 10 секунд через Bot API. Панель обрабатывает это автоматически.
  • Тестовые платежи Stars: в Telegram есть режим тестовых платежей через @ShopBot — используйте его для проверки без реального списания Stars.

Тестирование

  1. Используйте тестовый Bot Token (зарегистрируйте отдельного бота через @BotFather) и тестовый Stars-invoice.
  2. В Telegram клиенте на iOS/Android в настройках разработчика включите Test Server — платежи там не списывают реальные Stars.
  3. Альтернатива: в @BotFather выполните /mybots → Settings → Payments → Test payments.

Возможные проблемы

  • Оплата не проходит, пользователь видит ошибку → проверьте, что бот активен и webhook работает. Stars-платёж полностью идёт через Telegram Bot API.
  • PreCheckoutQuery не отвечает вовремя → панель должна ответить за 10 секунд. Если база данных или сервис замедлен — платёж будет отклонён Telegram.
  • Stars не зачислились после оплаты → убедитесь, что событие SuccessfulPayment обрабатывается в боте. Проверьте логи панели.
