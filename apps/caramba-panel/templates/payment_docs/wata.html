WATA — СБП и карты РФ, физлица OK

Российский платёжный сервис с поддержкой СБП и карт. Работает с физлицами без ИП. Аутентификация через JWT-токен + RSA публичный ключ для проверки подписи webhook.

Для РФ без ИП KYC: лёгкий Комиссия: от 2% СБП · Карты РФ

Когда подойдёт

  • Нужна низкая комиссия (от 2%) среди российских провайдеров для физлиц.
  • Ваша аудитория платит через СБП или карты российских банков.
  • Вы хотите работать без ИП и без крупного пакета документов.
  • Нужна надёжная RSA-подпись webhook вместо симметричного HMAC — WATA использует асимметричную криптографию.

Регистрация

  1. Откройте wata.pro и нажмите Регистрация.
  2. Укажите email и пароль. Подтвердите email.
  3. В личном кабинете пройдите верификацию физлица: потребуется паспорт (скан/фото разворота с фото).
  4. Создайте магазин: Магазины → Создать. Укажите название и URL вашего сервиса.

Где взять ключи

  1. В кабинете перейдите: Магазины → ваш магазин → API и интеграция.
  2. Скопируйте JWT Token — это ваш токен для аутентификации запросов к WATA API.
  3. Скачайте или скопируйте Public Key (PEM-формат) — он нужен для верификации подписи входящих webhook-уведомлений.
  4. Вставьте JWT Token в поле «WATA JWT Token» (wata_jwt_token) в настройках панели.
  5. Вставьте содержимое Public Key (включая строки -----BEGIN PUBLIC KEY-----) в поле «WATA Public Key» (wata_public_key).

Webhook URL

Добавьте в кабинет WATA следующий URL для уведомлений:

{{ panel_url }}/api/webhooks/payment/wata

Где настроить: Магазины → ваш магазин → Настройки → Webhook URL. Вставьте URL выше и сохраните.

Особенности

  • Проверка подписи: заголовок X-Signature. Значение — RSA-SHA512 подпись тела запроса; верификация производится с помощью вашего PEM Public Key. Панель проверяет автоматически.
  • JWT Token имеет срок жизни — периодически обновляйте его в кабинете WATA и в настройках панели.
  • Если панель получает webhook с неверной подписью, проверьте, что Public Key скопирован полностью, включая заголовок и подвал PEM-блока.
  • Работает только с РФ-картами и СБП; зарубежные карты не поддерживаются.

Тестирование

  1. WATA может предоставлять тестовый режим — уточните наличие sandbox в их поддержке (wata.pro).
  2. Если sandbox недоступен: создайте тестовый инвойс на 1 ₽ через панель и оплатите вручную через СБП.
  3. Проверьте получение webhook в разделе Logs панели.

Возможные проблемы

  • Webhook не приходит → убедитесь, что URL панели доступен снаружи и HTTPS-сертификат действителен. WATA требует HTTPS.
  • Подпись не совпадает → проверьте, что Public Key вставлен полностью (включая -----BEGIN PUBLIC KEY----- и -----END PUBLIC KEY-----). Пробелы и переносы строк важны.
  • JWT Token устарел → зайдите в кабинет WATA и сгенерируйте новый токен. Обновите поле wata_jwt_token в настройках панели.
  • Магазин на модерации → обратитесь в поддержку WATA через Telegram или email, указанный на сайте.
