OxaPay — крипта с поддержкой РФ, комиссия 0.4%

Крипто-агрегатор, популярный среди российских пользователей и разработчиков. Минимальный KYC, 0.4% комиссия, Telegram-поддержка. Подходит как основной или резервный крипто-канал.

Крипта KYC: минимальный Комиссия: 0.4% USDT · BTC · ETH · TON · и другие

Когда подойдёт

  • Нужна самая низкая комиссия среди крипто-провайдеров (0.4%) при адекватной надёжности.
  • Ваши пользователи — из России или СНГ, платят криптой. OxaPay известен в этом сегменте.
  • Нужна быстрая и простая интеграция с одним API-ключом (merchant key).
  • Хотите использовать Telegram для оперативной поддержки от команды OxaPay.

Регистрация

  1. Откройте oxapay.com и нажмите Sign Up.
  2. Укажите email и пароль. Подтвердите email.
  3. В кабинете перейдите в Merchants → Create Merchant. Укажите название вашего магазина и URL.
  4. KYC минимальный — для старта достаточно email. При росте оборота могут запросить дополнительные данные.

Где взять ключи

  1. В кабинете перейдите: Merchants → ваш мерчант → API Keys.
  2. Скопируйте Merchant Key — единственный ключ, необходимый для интеграции.
  3. Вставьте Merchant Key в поле «OxaPay Merchant Key» (oxapay_merchant_key) в настройках панели.

Webhook URL

Добавьте в кабинет OxaPay следующий URL для уведомлений:

{{ panel_url }}/api/webhooks/payment/oxapay

Где настроить: Merchants → ваш мерчант → Settings → Callback URL. Вставьте URL выше и сохраните изменения.

Особенности

  • Проверка подписи: заголовок HMAC. Значение — SHA512 hex от тела запроса. Ключ для HMAC — ваш Merchant Key. Панель проверяет автоматически.
  • OxaPay поддерживает TON, что важно для рынка РФ и интеграции с Telegram-экосистемой.
  • Поддержка в Telegram доступна через официальный канал OxaPay — быстрый ответ на технические вопросы.
  • Вывод средств на внешний крипто-кошелёк производится из раздела Payouts в кабинете.
  • В РФ OxaPay работает стабильно; API доступен без VPN.

Тестирование

  1. OxaPay предоставляет тестовый режим — переключите мерчант в режим Sandbox в настройках (Merchants → ваш мерчант → Settings → Mode).
  2. В sandbox-режиме создайте инвойс через панель — оплата симулируется без реальных средств.
  3. После тестирования переключите мерчант обратно в Live режим.

Возможные проблемы

  • Webhook не приходит → убедитесь, что Callback URL сохранён и URL панели доступен по HTTPS. Посмотрите историю вызовов в Merchants → ваш мерчант → Webhook Logs.
  • Подпись не совпадает → убедитесь, что Merchant Key скопирован без лишних символов. SHA512 чувствителен к точному значению ключа.
  • Мерчант заблокирован → обратитесь в поддержку OxaPay через Telegram. Укажите ваш Merchant ID и опишите ситуацию.
  • Инвойс в статусе «waiting» → пользователь ещё не отправил оплату. Инвойс истекает через заданное время (по умолчанию 30 минут). После истечения создайте новый.
