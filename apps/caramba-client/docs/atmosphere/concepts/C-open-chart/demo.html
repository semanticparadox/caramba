Open Chart

Фон приложения это карта сети. Отключено: вокруг вас замкнутая граница, маршруты обрываются тупиками, мир заштрихован. Подключено: границы нет, сетка карты проявляется, каждый маршрут идёт до своей станции.

Состояние

Режим

canvas: static frame, 0 fps
Клавиши 1 to 5. Прямые ссылки: #connected, #error,light, #connecting,reduce
ГраницаЗамкнутая октагональная рамка вокруг диска. Не круг, чтобы не спорить с кольцом статуса.
ШтриховкаКартографическая отметка запретной зоны. Здесь запретна вся зона снаружи.
ТупикиПоперечная засечка там, где маршрут упирается в границу.
СеткаГрадусная сетка появляется только при подключении. Одна главная линия проходит через центр диска.
СтанцииПолые квадраты офлайн, залитые с волосяным кольцом онлайн. Коды стран моноширинным, только в подключённом состоянии.
ПокойОтключено и подключено это статичный кадр. Тикер остановлен, кадры не рисуются.
