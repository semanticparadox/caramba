# База знаний Caramba Connect (Telegraph)

Пользовательские инструкции, которые бот и мини-приложение показывают по ссылкам из настроек `guide_url_<id>`. Источник истины: файлы `ru/*.md` в этой папке. Telegraph получает результат скриптом, руками страницы в Telegraph не правятся: следующая публикация перезапишет правку.

## Структура

| id | Файл | Настройка бота | Что это |
|----|------|----------------|---------|
| `index` | `ru/index.md` | `guide_url_index` | Корневая «Ваши следующие шаги»: три шага и ссылки на всё остальное |
| `platforms` | `ru/platforms.md` | нет | Старая корневая «Как подключить» (path сохранён, старые кнопки в чатах не ломаются), теперь оглавление по устройствам |
| `app` | `ru/app.md` | `guide_url_app` | Что умеет приложение |
| `link` | `ru/link.md` | нет | Подключение по ссылке `caramba://` (на неё ведут корневая и платформенные страницы) |
| `plans` | `ru/plans.md` | `guide_url_plans` | Тарифы и подарок |
| `devices` | `ru/devices.md` | `guide_url_devices` | Устройства: лимит, имена, отвязка |
| `faq` | `ru/faq.md` | `guide_url_faq` | Если не подключается |
| `android`, `windows`, `macos`, `linux` | `ru/<id>.md` | `guide_url_<id>` | Установка Caramba Connect |
| `ios`, `tv`, `router` | `ru/<id>.md` | `guide_url_<id>` | Подключение по ссылке подписки (сторонние клиенты) |

`pages.json` связывает id, файл, ключ настройки и path страницы Telegraph. Path у страниц с `null` появится после первой публикации: скрипт запишет его сам.

## Markdown, который понимает скрипт

- `# Заголовок` первой строкой: title страницы (в текст не попадает).
- `## Раздел` → h3, `### Подраздел` → h4 (других заголовков в Telegraph нет).
- Абзацы, списки `-` и `1.`, цитаты `>`, линейка `---`, блок кода в ``` ```, картинка `![подпись](https://…)` отдельной строкой.
- Инлайн: `**жирный**`, `*курсив*`, `` `код` ``, `[текст](https://…)`.
- Ссылка на другую страницу базы: `[текст](guide:<id>)`, URL подставится из `pages.json`.
- Вложенных списков, таблиц и HTML нет.

Стиль: русский, короткие абзацы, названия кнопок в «кавычках» и жирным ровно так, как они написаны в боте и приложении, без длинных тире. Факты только из кода и документации клиента (`apps/caramba-client`), бота (`apps/caramba-panel/src/bot`) и мини-приложения (`apps/caramba-app`): если функции нет в коде, её нет и здесь.

## Публикация

Токен аккаунта Telegraph лежит в настройке панели `telegraph_access_token`. Скрипт берёт его только из переменной окружения и никуда не пишет.

```
# проверка без сети: узлы, размеры, неразрешённые ссылки
python3 scripts/telegraph-publish.py --dry-run --summary

# публикация всех страниц
TELEGRAPH_ACCESS_TOKEN='…' python3 scripts/telegraph-publish.py

# одна страница (только уже созданные, иначе ссылки guide: не разрешатся)
TELEGRAPH_ACCESS_TOKEN='…' python3 scripts/telegraph-publish.py --only faq
```

Как это работает:

1. Страницы без `path` создаются заглушкой (`createPage`), path и url сразу пишутся в `pages.json`.
2. Все страницы получают полное содержимое (`editPage`), ссылки `guide:<id>` уже разрешены.
3. В конце скрипт печатает `guide_url_<id> = <url>` для настроек бота (админка → Settings → Guides). Для новых страниц эти ключи нужно заполнить один раз; у существующих URL не меняются.

После публикации закоммитьте обновлённый `pages.json`.

Тесты конвертера: `python3 -m unittest scripts/test_telegraph_publish.py`.
