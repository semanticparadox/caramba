# Caramba Connect · Установка на Windows

Нужна Windows 10 или 11, 64-бит.

## 1. Скачайте

В боте: **«📥 Скачать приложение»** → **«🪟 Скачать для Windows»** или **«📦 Получить файл в Telegram»** → Windows. Два варианта:

- **`Caramba-Connect-Setup-x64.exe`**, установщик (рекомендуем). Ставит программу, добавляет ярлык в меню Пуск и регистрирует ссылки `caramba://`, чтобы ссылка из бота открывала приложение.
- **`Caramba-Connect-Windows-x64-portable.zip`**, портативная версия. Распакуйте папку `Caramba Connect` и запускайте `caramba_client.exe` из неё. Ссылки из бота она не открывает, ссылку вставляют руками.

## 2. Два предупреждения Windows

Оба ожидаемы, ничего не сломано.

**SmartScreen: «Windows защитила ваш компьютер».** Сборки не подписаны сертификатом. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Если файл пришёл из Telegram, окна может и не быть.

**Запрос прав администратора (UAC).** Появляется при установке и при каждом запуске приложения. Системный туннель на Windows работает через драйвер wintun, а он создаёт сетевой адаптер только с правами администратора, поэтому приложение запрашивает их само. Отдельно «Запуск от имени администратора» выбирать не нужно.

## 3. Подключите по ссылке из бота

1. В боте нажмите **«🔗 Подключить Caramba Connect»** (или `/link`) и **«📋 Скопировать ссылку»**.
2. Если ставили установщиком: нажмите на ссылку `caramba://connect…` в Telegram Desktop или браузере, откроется Caramba Connect с экраном «Подключить панель». Браузер один раз спросит «Открыть Caramba Connect?», подтвердите. Проверьте имя оператора и нажмите **«Подключить»**.
3. Если ссылка не открылась (портативная версия или ссылка показана текстом): в приложении **«Добавить подключение»** → **«Вставить»** → **«Продолжить»** → **«Подключить»**.

Подробнее: [подключение по ссылке](guide:link).

## 4. Нажмите «Подключить» и выберите, как ловить трафик

На главном экране одна большая кнопка. После подключения обратите внимание на строку **«Прокси 127.0.0.1:7890»** под ней: по умолчанию на компьютере приложение работает как локальный прокси и не перехватывает трафик системы само.

Два способа пустить трафик через VPN:

- **Весь компьютер**: Настройки → «Сеть и ядро» → **«Захват трафика»** → **«Системный TUN»**. Именно для этого нужны права администратора из шага 2. Выбор запоминается.
- **Только браузер или отдельные программы**: укажите в их настройках прокси адрес `127.0.0.1`, порт `7890` (SOCKS5 или HTTP). Адрес копируется из меню значка в трее.

## Значок в трее и автозапуск

Приложение живёт в трее: подключить и отключить, сменить сервер, открыть окно. В Настройках → «Приложение»: **«Запускать при входе в систему»**, **«При закрытии и сворачивании окна»** (сворачивать в трей или завершать), **«При запуске»** (показывать окно или только значок).

## Обновление и удаление

- Обновление: запустите новый `Setup.exe` поверх, он закроет приложение, заменит файлы и сохранит настройки.
- Удаление: Параметры → Приложения → Caramba Connect → Удалить, либо ярлык «Удалить Caramba Connect» в меню Пуск. Портативную версию просто удаляют папкой.

## Известные ограничения

- Подписи кода нет, SmartScreen будет предупреждать при каждой новой версии.
- Второй клик по ссылке при уже открытом приложении запускает вторую копию: закройте лишнюю.
