# Caramba Connect · Установка на Linux

Сборка для x86-64. Пакета deb или AppImage пока нет: приложение ставится скриптом из архива.

## 1. Скачайте

В боте: **«📥 Скачать приложение»** → **«🐧 Скачать для Linux»** или **«📦 Получить файл в Telegram»** → Linux. Придёт `Caramba-Connect-Linux-x64.tar.gz`.

## 2. Установите

В терминале, в папке с архивом:

```
tar -xzf Caramba-Connect-Linux-x64.tar.gz
sudo ./caramba-connect/install.sh
```

Скрипт спросит пароль sudo и сделает всё сам:

- скопирует приложение в `/opt/caramba-connect`;
- добавит ярлык в меню приложений и зарегистрирует ссылки `caramba://`, чтобы ссылка из бота открывала приложение;
- выдаст приложению право поднимать туннель (`setcap cap_net_admin`), чтобы запускать его обычным пользователем без sudo.

Нужна утилита `setcap`: пакет `libcap2-bin` в Debian и Ubuntu, `libcap` в Fedora и Arch.

Запуск: из меню приложений или `/opt/caramba-connect/caramba_client`. Удаление: `sudo ./caramba-connect/install.sh --uninstall` из распакованного архива.

## 3. Подключите по ссылке из бота

1. В боте нажмите **«🔗 Подключить Caramba Connect»** (или `/link`) и **«📋 Скопировать ссылку»**.
2. Нажмите на ссылку `caramba://connect…` в Telegram или браузере: откроется Caramba Connect с экраном «Подключить панель». Проверьте имя оператора и нажмите **«Подключить»**.
3. Если ссылка не открылась: в приложении **«Добавить подключение»** → **«Вставить»** → **«Продолжить»** → **«Подключить»**.

Проверить, что ссылки зарегистрированы: `xdg-mime query default x-scheme-handler/caramba` должно ответить `caramba-connect.desktop`.

Подробнее: [подключение по ссылке](guide:link).

## 4. Нажмите «Подключить» и выберите, как ловить трафик

На главном экране одна большая кнопка. По умолчанию на компьютере приложение работает как **локальный прокси**: после подключения под кнопкой видна строка **«Прокси 127.0.0.1:7890»**.

- **Весь компьютер**: Настройки → «Сеть и ядро» → **«Захват трафика»** → **«Системный TUN»**. Право на это уже выдал `install.sh`. Выбор запоминается.
- **Только браузер или отдельные программы**: укажите в их настройках прокси `127.0.0.1:7890` (SOCKS5 или HTTP). Адрес копируется из меню значка в трее.

## Значок в трее

Подключить и отключить, сменить сервер, открыть окно. Настройки → «Приложение»: **«Запускать при входе в систему»**, **«При закрытии и сворачивании окна»**, **«При запуске»**.

## Обновление

Распакуйте новый архив и снова запустите `install.sh`: старая установка заменяется целиком, настройки в домашней папке остаются.

Не подключается: [если не подключается](guide:faq). Дальше: [«Ваши следующие шаги»](guide:index) · [что умеет приложение](guide:app).
