# Caramba Connect · Установка на Android

Caramba Connect для Android ставится из файла APK: приложения пока нет в Google Play. Установка занимает минуту.

## 1. Скачайте APK

- В боте нажмите **«📥 Скачать приложение»** → **«📲 Скачать для Android»** (файл с сайта) или **«📦 Получить файл в Telegram»** → Android (файл приходит прямо в чат, работает даже если сайт заблокирован).
- Команда `/apk` в боте делает то же самое.

## 2. Установите

1. Откройте скачанный файл.
2. Android спросит разрешение на установку из неизвестного источника для Telegram (или браузера). Разрешите и вернитесь к установке.
3. Дождитесь «Приложение установлено». На рабочем столе появится значок Caramba Connect с корабликом.

## 3. Подключите по ссылке из бота

1. В боте нажмите **«🔗 Подключить Caramba Connect»** (или `/link`).
2. Нажмите на ссылку в сообщении: откроется Caramba Connect с экраном «Подключить панель». Проверьте имя оператора и нажмите **«Подключить»**.
3. Если ссылка открылась не в приложении: нажмите **«📋 Скопировать ссылку»**, в приложении **«Добавить подключение»** → **«Вставить»** → **«Продолжить»** → **«Подключить»**.

Ссылка работает один раз и 30 минут. Подробнее: [подключение по ссылке](guide:link).

## 4. Нажмите «Подключить»

На главном экране нажмите большую кнопку. При первом подключении Android спросит разрешение на VPN-подключение: подтвердите. Пока туннель работает, в шторке висит уведомление о подключении.

## Обновление

Новую версию ставят поверх старой тем же способом: скачали APK из бота, открыли, установили. Настройки и подключения сохраняются.

## Если что-то не так

- «Заблокировано администратором» или «установка запрещена»: включите установку из неизвестных источников для приложения, из которого открываете APK (Настройки Android → Приложения → Telegram → «Установка неизвестных приложений»).
- Не подключается: [если не подключается](guide:faq).
