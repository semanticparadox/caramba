# Caramba Connect · Если не подключается

Короткие ответы на самые частые вопросы. Не нашли свой? Внизу контакты поддержки.

## Ссылка из бота не открывает приложение

Так бывает в портативной версии для Windows (она не регистрирует ссылки), на Linux без `install.sh` и на Mac, если приложение ещё ни разу не запускали. Скопируйте ссылку (**«📋 Скопировать ссылку»** под сообщением бота), откройте приложение → **«Добавить подключение»** → **«Вставить»** → **«Продолжить»** → **«Подключить»**.

## «Ссылка не подошла» или приглашение истекло

Ссылка работает один раз и только 30 минут. Нажмите в боте **«🔗 Подключить Caramba Connect»** ещё раз и вставьте новую.

## «Не удалось подключиться. Проверьте сеть и нажмите снова»

По порядку:

1. Проверьте, что интернет вообще есть (откройте любой сайт без VPN).
2. Нажмите **«Подобрать лучший узел»**: приложение проверит все серверы и выберет рабочий.
3. Настройки → «Подключение» → **«Тип подключения»**: попробуйте «Авто», затем VLESS Reality (устойчивее всего к блокировкам). Hysteria2 и TUIC быстрее, но работают не в каждой сети: они на UDP, который провайдеры иногда режут.
4. Серверы → **Relay (вход)**: если оператор предлагает вход через релей, выберите его.
5. Проверьте дату и время на устройстве: при расхождении больше пары минут защищённое соединение не поднимется.
6. Настройки → «Автонастройка» → **«Подобрать настройки заново»**.

## Подключено, но сайты не открываются

- Посмотрите **режим** в Настройках → «Правила трафика». В «Россия (умный)» через VPN идут только заблокированные сервисы, остальное напрямую. Нужно всё через VPN: выберите «Полный обход».
- Проверьте «Правила по сайтам» и «Правила по приложениям»: список «только выбранные» пускает через VPN ровно то, что в нём перечислено.
- Отключите и подключите заново: после смены настроек приложение показывает баннер про переподключение.

## «Занято максимум устройств»

Все слоты тарифа заняты. Отвяжите лишнее устройство: [устройства](guide:devices).

## «Дневной лимит израсходован» или «Подписка закончилась»

На бесплатном тарифе 200 МБ в день, квота пополняется каждые сутки. Подписка истекла: продлите её в боте или в приложении (Профиль → «Купить или продлить»). Подробнее: [тарифы](guide:plans).

## «Оператор не отдаёт список узлов»

Проверьте подписку в боте: она могла закончиться или ждать подтверждения. Если всё активно, потяните список серверов вниз, чтобы запросить его заново.

## Windows

- **SmartScreen** («Windows защитила ваш компьютер»): нажмите «Подробнее» → «Выполнить в любом случае». Сборки не подписаны сертификатом.
- **Запрос прав администратора при каждом запуске**: так и должно быть. Системный туннель на Windows работает через драйвер wintun, а он создаёт сетевой адаптер только с правами администратора.
- Подключено, а трафик компьютера идёт мимо: по умолчанию на компьютере приложение работает как локальный прокси `127.0.0.1:7890`. Либо укажите этот адрес в настройках прокси системы или браузера, либо в Настройках → «Сеть и ядро» → «Захват трафика» выберите «Системный TUN», тогда через VPN пойдёт всё.
- Ссылка из бота не открывает приложение: вы поставили портативную версию из ZIP. Вставьте ссылку руками или поставьте `Setup.exe`.

Подробнее: [Windows](guide:windows).

## Mac

- «Приложение не удаётся открыть»: оно не подписано. Нажмите на него правой кнопкой → «Открыть» → ещё раз «Открыть». Это нужно один раз.
- Ссылка из бота не открывает приложение: запустите Caramba Connect хотя бы один раз из «Программ», после этого macOS знает, кому отдавать ссылки `caramba://`. Пока не открывается, вставляйте ссылку руками.
- На Mac приложение работает как локальный прокси на `127.0.0.1:7890`: чтобы трафик пошёл через него, укажите этот адрес в настройках прокси системы или браузера. Подробнее: [Mac](guide:macos).

## Linux

- Запускайте `install.sh` из распакованного архива: он выдаёт приложению право поднимать туннель и регистрирует ссылки `caramba://`. Без него ссылка из бота не откроет приложение.
- Нет `setcap`: поставьте пакет `libcap2-bin` (Debian, Ubuntu) или `libcap` (Fedora, Arch).
- Трафик компьютера идёт мимо: по умолчанию приложение работает как локальный прокси `127.0.0.1:7890`. Пропишите его в системе или браузере, либо в Настройках → «Сеть и ядро» → «Захват трафика» выберите «Системный TUN».

Подробнее: [Linux](guide:linux).

## Android

- «Заблокировано: установка из неизвестного источника»: разрешите установку для Telegram (или браузера, откуда скачали) и повторите.
- При первом подключении Android спросит разрешение на VPN-подключение: нажмите «ОК».

Подробнее: [Android](guide:android).

## iPhone и iPad

Своего приложения там пока нет. Подключайтесь по ссылке подписки в Hiddify, Happ или другом клиенте: [инструкция](guide:ios).

## Поддержка

- В боте: кнопка **«❓ Поддержка»** или чат [@caramba_support](https://t.me/caramba_support).
- В приложении: Профиль → **«Запросы в поддержку»**. Если приложение показало «Подробность для поддержки», перешлите этот текст: по нему проблему находят быстрее.
