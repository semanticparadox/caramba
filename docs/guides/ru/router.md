# Caramba Connect · Роутер и ручная настройка

Для роутера нужна **прямая ссылка одного подключения**, а не вся подписка. Где взять: в боте откройте мини-приложение (кнопка меню слева от поля ввода) → **«Серверы»** → у нужного сервера **«Прямая ссылка»** → выберите тип подключения и маршрут (прямой или через релей) → **«Скопировать»**. Там же есть QR.

## Какой тип выбрать

- **VLESS Reality**: лучший против блокировок, по умолчанию.
- **Hysteria2**: максимальная скорость, если провайдер не режет UDP.
- **VLESS WS / gRPC / HTTPUpgrade**: когда нужно пройти через CDN или релей.

## Keenetic

1. Установите компонент **«Прокси-клиент»** (или **sing-box** из репозитория Entware).
2. Добавьте новое подключение и вставьте прямую ссылку `vless://…`.
3. Назначьте политику: какие устройства ходят через VPN.

## OpenWrt

1. Установите пакет `sing-box` (`opkg install sing-box`).
2. Сгенерируйте конфиг из прямой ссылки любым конвертером или возьмите готовый JSON по ссылке подписки, добавив к ней `?client=singbox`.
3. Включите режим TUN и направьте в него нужные подсети.

## Другие роутеры

Подойдёт любая прошивка с поддержкой sing-box или Xray: везде нужна та же прямая ссылка. Сомневаетесь: напишите в поддержку, подскажем по модели.

## Если не подключается

- Попробуйте другой сервер или другой тип подключения из списка выше.
- Из России при отключениях внешнего интернета выберите маршрут **«Через релей»** в окне «Прямая ссылка».
- Проверьте дату и время на роутере: при расхождении больше пары минут защищённое соединение не поднимется.
- Не помогло: кнопка **«❓ Поддержка»** в боте или [@caramba_support](https://t.me/caramba_support).
